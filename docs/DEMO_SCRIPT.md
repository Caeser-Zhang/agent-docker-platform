# 平台演示脚本 — 知识库应用与运营 + 三大能力

版本 v1 · 2026-09-16 · 预计总时长 20 分钟（含收尾）

## 演示主题

**「从一次提问到一份汇报：一个聊天框走完全程」**

用一条工作流串起所有能力，而不是逐个功能点罗列：

```
管理员接入知识库 → 授权员工 → 员工对话检索（可溯源）
→ 一句话画流程图 → 选三下生成 PPT → 浏览器内预览迭代 → 打包下载
→ 管理员撤销授权（安全闭环）
```

三个核心卖点，贯穿全程反复强调：

| 卖点 | 证据点 |
|---|---|
| **简单** | 用户零学习成本：像聊天一样提问，不用学检索语法；PPT 只需三组单选 |
| **高效** | 授权即时生效（不重启容器、不重新登录）；Excel 批量导入成员；`@ 引用当前页` 精准迭代 |
| **可信/可管控** | 每条结论带引用徽章可溯源；Key 永不回显；撤销授权后历史引用立即 403 |

## 二、演示脚本

### 开场白（1 分钟）

> "今天演示我们 Agent 平台的三大能力：知识库搜索、流程图生成、PPT 生成，以及背后的运营管控体系。
> 我不会逐个功能介绍，而是走一遍员工的真实工作流：**从问一个问题，到拿到一份可以汇报的 PPT，全程不离开一个聊天框。**"

---

### 第 1 幕 · 运营侧：知识库接入与授权（admin，约 3 分钟）

**场景设定**：管理员接到需求——把公司规范知识库开放给项目组。

**操作步骤**：

1. admin 标签页 → 顶部「权限」进入知识库权限页
2. **创建知识领域**：填名称（如「工程规范」）+ 描述 + API Key
3. **关联物理库**：给领域添加 1~2 个库，展示一个领域可管多个库
4. **成员授权**（三种方式依次快速展示）：
   - 单个：搜索用户名/工号，点击授权
   - 批量粘贴：把一列工号直接贴进文本框 → 预览 → 提交
   - **Excel 导入**：上传名单 → 预览确认页（匹配 / 已授权 / 未匹配三分类）→ 提交
5. 指一下**公共/私有**类型标签：全员公共库 vs 保密私有库

**台词**：

> "管理员接入一个知识库只需要三步：建领域、关联库、授权人。
> 注意两点：第一，API Key 是**只写不读**的，录入后任何接口都不回显明文，真实密钥只在后端内存解密，用户和容器全程接触不到。
> 第二，授权**即时生效**——不需要重启容器，用户也不需要重新登录。批量授权支持粘贴工号或直接导入 Excel，导入前还有预览确认，未匹配的工号会明确列出来，不会误授权。"

**切普通用户标签页**：侧栏知识库面板已出现「工程规范」领域卡片。

> "看，用户这边立刻就能看到自己被授权的知识领域，我们直接进入使用环节。"

---

### 第 2 幕 · 知识库搜索（用户，约 4 分钟）— 关键词：可信、可溯源

**操作步骤**：

1. 用户标签页新建会话
2. 直接问预跑验证过的业务问题，如：*"XX 系统的超时重试规范是什么？"*
3. 回答流式输出时，**展开工具调用卡片**，让观众看到 `fastk databases` → `fastk search` 的检索过程
4. **高光动作**：点击回答里的引用徽章 `[[chunk:...]]` → 弹窗展示知识库原文片段 + 附图

**台词**：

> "用户不需要学任何检索语法，像聊天一样提问就行。Agent 会自动完成三步：先看自己被授权了哪些库，再做混合检索，最后组织答案。
> 工具调用过程是完全透明、可折叠展开的——你能看到它查了什么、怎么查的。
> 最重要的是这个：**每条结论都带引用徽章**，点开就是知识库里的原文片段，连附图都会经过鉴权后展示。答案不是模型编的，是库里写的。可溯源，才能防幻觉，这是企业场景和玩具场景的分水岭。"

**可选加分项**（时间充裕时）：

> 追问一句 *"把刚才的规范整理成覆盖度分析：库里还有哪些相关文档？"* —— 触发 fastk-analyze，展示 agent 从「单点检索」升级到「面上分析」的能力。

---

### 第 3 幕 · 流程图生成（用户，约 3 分钟）— 关键词：一句话出图

**⚠️ 演示前必须口头设定预期：平台交付 PlantUML `.puml` 标准源码，不在平台内渲染图片。**

**操作步骤**：

1. **同一会话**继续（体现上下文连续），用快捷技能入口选「流程图生成」
2. 输入：*"根据刚才查到的超时重试规范，画出重试流程的活动图"*
3. 生成 `.puml` 文件 → 文件面板预览源码 → 展示可下载

**台词**：

> "接着刚才的检索结果，一句话就能把规范变成流程图。注意我没有重新描述需求——agent 记得上下文，这就是同一个会话里工作的价值。
> 平台交付的是 **PlantUML 标准源码**：可以直接进代码仓库做版本管理、在 CI 里渲染、被任何 PlantUML 工具链消费。对工程团队来说，源码比一张 PNG 更有价值——它可以 diff、可以评审、可以复用。"

---

### 第 4 幕 · PPT 生成（用户，约 6 分钟，压轴）— 关键词：从知识到交付

**操作步骤**：

1. 快捷技能弹窗展示**三组单选**：
   - 模板（来自共享模板库）
   - 配色（调色板）
   - 版式配方（风格）
2. 输入主题（做三能力串联）：*"基于知识库里的 XX 规范，生成一份 5 页的团队宣讲 PPT"*
3. 生成过程流式展示；`present_file` 交付时**自动弹出预览标签页**
4. **高光 1**：pptx-wasm 浏览器端高保真渲染 + 缩略图导航 + 缩放——不装 Office、不下载就能看
5. **高光 2（迭代修改）**：在预览里翻到某一页 → 点 `@ 引用当前页` → 输入 *"这一页标题改成……"* —— 精准迭代，不整份重生成
6. 收尾：文件面板多选 → zip 打包下载

**台词**：

> "生成 PPT 不需要写复杂的 prompt——选三下单选就够了。模板来自公司统一维护的**共享模板库**，管理员负责上架下架，所有员工生成的 PPT 天然符合品牌规范，这一点对企业很重要。
> 生成完成后自动弹出预览，这是浏览器端的高保真渲染，不需要安装 Office、不需要下载。
> 想改某一页？直接**引用这一页**说改什么，只迭代这一处，不用整份重来。
> 最后打包下载，一份基于公司知识库、带规范流程图的汇报 PPT 就交付了。
> 回头看整个过程：**从提问到成品，没有离开这个页面，没有切换任何工具。**"

---

### 第 5 幕 · 安全闭环：撤销授权（admin，约 2 分钟）

**这一幕很短但冲击力最强，务必演。**

**操作步骤**：

1. 切回 admin 标签页 → 权限页 → 撤销该用户的领域授权（点击即撤销）
2. 切回用户标签页 → 翻到**历史会话** → 点击之前的引用徽章 → **403，立即失效**
3. 侧栏领域卡片同步消失（可刷新展示）

**台词**：

> "最后看管控。管理员点击撤销，**即时生效**——用户历史会话里的引用徽章立刻变成 403，不残留任何访问权。
> 背后的机制是：容器内的所有知识库请求都经过平台的**白名单代理**，只放行只读接口，真实密钥由平台按授权动态注入。用户拿不到 Key，容器也拿不到 Key，权限判定收敛在一个点上，所以才能做到秒级收放。
> 员工离职、项目结束、保密等级变化——运营侧一个点击就完成管控，这就是'运营'两个字的含义。"

---

### 收尾（1 分钟）

> "总结一下今天的演示：
> **对员工**——像聊天一样查知识库、画流程图、做 PPT，零学习成本，每条回答可溯源；
> **对管理员**——领域化授权、Excel 批量导入、模板库统一管控、秒级收放权限；
> **对平台**——一套权限体系、一个对话入口、一个文件工作区贯穿三大能力。
> 接入简单、使用简单、管控严格。谢谢大家，欢迎提问。"

## 三、风险预案

| 风险 | 概率 | 预案 |
|---|---|---|
| LLM 响应慢 / 卡住（最大风险） | 中 | 切到**预跑的备份会话**讲结果："这是刚才同款生成的结果"；不要现场反复重试 |
| PPT 生成耗时超预期 | 中 | 现场版控制在 5 页以内；讲解台词本身就是填充时间；极端情况切备份会话 |
| PPT 排版翻车 | 低 | 只用预跑验证过的模板+配色组合；真翻车就现场 `@ 引用当前页` 修——顺势展示迭代能力 |
| 知识库检索命中差 | 低 | 只用预跑验证过的问题；命中差时 agent 会自动放宽重试，可顺势讲鲁棒性 |
| fastk 上游不可达 | 低 | 演示前 curl 验证；不可达则跳过徽章弹窗，只讲检索过程 |
| 观众自由提问翻车 | 中 | 引导提问限定在已授权库主题内；答不上来时坦诚展示"知识库没有相关内容"也是防幻觉卖点 |
| 容器冷启动等待 | 低 | 演示账号容器提前启动；万一重启，用第 1 幕 admin 操作填充时间 |

## 五、现场操作备忘

- 快捷技能入口：聊天输入框旁（PPT 生成 / 流程图生成）
- 引用徽章：回答正文中的 `[[chunk:库名/id]]` 渲染为可点击徽章
- `@ 引用`：文件面板预览内一键插入；PPTX 预览可引用**当前页**
- 文件面板：树状浏览 / 多选 / zip 下载 / PPTX 高保真预览
- 权限页入口：Chat 顶部「权限」按钮（仅 admin 可见）
- 交付预览：agent 通过 `present_file` 交付时自动弹标签页
