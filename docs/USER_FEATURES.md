# 用户侧功能特性

本文按角色整理平台**已上线**的用户侧功能：普通用户（`role=user`）与管理员（`role=admin`）。
架构、部署与容器加固说明见 [README.md](../README.md)，接口契约见 [API.md](API.md)。

---

## 角色与权限模型

| 项 | 说明 |
|---|---|
| 角色 | `user`（普通用户）/ `admin`（管理员） |
| 管理员来源 | **首个注册用户自动成为 admin**；或 `AGENT_ADMIN_USERNAMES`（逗号分隔用户名）中的账号在登录时自动提升 |
| 权限校验 | 后端每个受保护端点**实时回读数据库角色**——降权后无需重新登录即刻生效 |
| 页面门控 | `chat`（对话，默认页）对所有用户开放；`admin`（管理后台）/ `library`（模板库）/ `kbaccess`（知识库权限）仅 admin 可进入 |
| 工号（uid） | 注册时可选填，缺省由平台自动分配（`10001` 起递增）；管理端容器列表与 UX 看板支持按工号检索、过滤 |
| 隔离边界 | 每用户一套独立容器 + 独立工作区卷；用户级密钥加密入库、仅本人可见；所有配置接口响应统一脱敏（API key 不回显明文） |

**配置三级作用域**（贯穿全文的关键概念）：

| 作用域 | 存储位置 | 谁能改 | 生效范围 |
|---|---|---|---|
| 全局级 | 宿主机 `opencode.json` + `~/.config/opencode/skills/` | 管理员（前端仅 admin 可见编辑入口） | 注入所有用户容器 |
| 项目级 | 容器卷 `/workspace/opencode.json`、`/workspace/.opencode/skills/` | 用户本人 | 仅本人工作区 |
| 用户级 | 平台数据库（密钥加密存储） | 用户本人 | 仅本人容器，注入时与全局配置合并 |

## 一、普通用户功能

### 1. 账号与登录

- 用户名 + 密码注册，注册即返回 JWT（有效期 24h）；登录响应含 `role`
- 接口限流：注册 10 次/IP/小时，登录 5 次/15 分钟（时序均衡，防用户名枚举）
- 登录后顶部显示角色标识；admin 额外获得顶部「模板库」「权限」「管理」三个入口按钮

### 2. 我的 Agent 容器

- **启动页（Welcome）**：未启动时展示引导页，一键启动专属容器
- **阶段化进度**：`creating → starting → warming → running` 实时轮询展示，失败可见原因
- 运行状态面板：容器状态、健康探测、运行时自省（镜像、端口、配置来源、被消毒剥离的字段）
- 自助操作：启动 / 停止 / 查看容器日志（最近 100 行）
- 空闲自动回收（默认 30 分钟无活动停止），再次进入页面可一键重启，工作区数据不丢

### 3. AI 对话

| 能力 | 说明 |
|---|---|
| 流式渲染 | SSE 逐段输出（单上游 + 环形缓冲 + 扇出，支持 `lastEventId` 断线重放）；**4 秒静默自动轮询兜底**，弱网不断流 |
| 多会话 | 创建 / 重命名 / 删除 / 总结（summarize）；切换会话自动恢复历史消息 |
| 消息块类型 | 正文、reasoning、工具调用卡（可折叠、含状态）、代码补丁、子任务、compaction、重试提示 |
| 工具审批卡 | SSE 事件驱动实时出现：允许一次 / 总是允许 / 拒绝 |
| Agent 提问卡 | 单选 / 多选 / 自定义输入，支持一次多问 |
| 消息级操作 | 重新生成、分叉（fork）、回退（revert，同时恢复文件改动） |
| 斜杠命令 | 输入 `/` 触发命令与 agent 补全 |
| `@` 引用 | 工作区文件模糊搜索（opencode `/find/file`）+ subagent 引用，选中转为 FilePart 随 prompt 下发 |
| Agent / 模型切换 | 运行时切换 primary agent（自动过滤 subagent）与模型；支持**单条消息级覆盖**，并可「设为会话默认」 |

### 4. 项目空间

- **新建项目**：在工作区创建 `projects/{名称}` 目录，会话绑定该目录
- **绑定已有目录**：把工作区中已存在的目录纳管为项目
- 会话列表**按项目分组**展示，切换项目即切换上下文
- 删除项目：仅删除其下的会话记录，**目录与文件保留**
- 项目目录创建后不可变（不支持重命名）

### 5. 快捷技能（生成器）

- **PPT 生成**：弹窗内三组单选——模板（来自共享模板库）、配色（调色板）、版式配方（风格），确认后自动启用 `pptx-generator` skill 并注入路径约束
- **流程图生成**：基于 plantuml，**只交付 `.puml` 源码**（平台内不渲染图片）

### 6. 附件与上传

- 输入框上传按钮（支持多选）：图片以 base64 内联随 prompt 发送（不落容器磁盘），其它文件写入容器工作区 `tmp/` 隔离目录（单文件 ≤10MB）
- 上传成功后自动在输入框追加 `@tmp/…` 引用，不污染工作区根目录

### 7. 工作区文件面板

| 能力 | 说明 |
|---|---|
| 树形浏览 | 目录折叠、刷新，自动剪除 `.git` / `node_modules` 等重目录 |
| 批量操作 | 多选、**zip 打包下载**、批量删除 |
| 预览 | HTML（iframe 沙箱）、Markdown、图片、文本/代码、**PPTX（`pptx-wasm` 浏览器端高保真渲染**，含缩略图导航与缩放） |
| `@ 引用` | 预览内一键把文件（或 PPTX 当前页）插入输入框 |
| 交付预览 | Agent 通过 `present_file` 主动交付产物时自动弹出标签页：按路径去重、关闭后记忆不再自动弹、可全局开关「自动弹出」 |

### 8. 知识库（fastk）接入

- **只读目录侧栏**：查看自己被授权的知识库列表与目录（`/api/kb/my-databases`、`/api/kb/my-catalog`）；后端不可达时软降级，不阻塞对话
- **Agent 侧检索**：容器内 MCP 工具（`list_databases` / `list_files` / `get_stats` / `toc` / `search` / `query` / `grep`）经平台 `/fastk/api` 白名单代理访问，凭据由平台注入，用户与容器都看不到密钥；**仅只读接口放行**
- **引用徽章**：回复中的 `[[chunk:db/id]]` 渲染为可点击徽章，弹窗展示命中片段正文与**鉴权后的附图**
- 授权被撤销后，历史徽章同样返回 403（不残留访问权）

### 9. 体验反馈

- 每条 assistant 回复可**点赞 / 点踩**；提交后**锁定不可取消**，重复提交幂等
- 点踩需选原因码（7 类）：`misunderstood`（理解偏差）/ `wrong_answer`（答案错误）/ `tool_failure`（工具失败）/ `too_verbose`（过于啰嗦）/ `ignored_constraints`（忽略约束）/ `interrupted`（被中断）/ `other`（其它）
- 可补充文字说明（≤500 字）；平台自动附带上下文快照（≤60000 字符，超限截断）
- 切换会话时自动回填已提交状态；提交限流 30 次/60 秒
- 反馈数据汇入管理员的用户体验看板

### 10. 配置面板（用户可用部分）

| 分区 | 用户能做什么 |
|---|---|
| **我的配置 · LLM** | 个人 Provider / 模型 CRUD，选择「激活 LLM」；密钥加密存储、界面脱敏 |
| **我的配置 · MCP** | 个人 MCP Server CRUD（Remote URL / Local Command）+ 启停 |
| **我的配置 · 内置 MCP** | 平台内置 MCP（如 `web_search`）的**个人开关**——只能收窄不能放开；管理员全局停用时该项置灰不可开启 |
| **项目配置** | 直接编辑 `/workspace/opencode.json`；项目级 Skill 增删改 + **zip 批量导入**（三种布局自适应，500 文件 / 单文件 5MB / 总量 20MB 上限） |
| **全局配置（只读）** | 查看管理员维护的 Provider / Skill；全局 MCP 列表仅 admin 可见 |
| **重载到容器** | `POST /api/config/reload`——合并用户级配置后重启自己的容器；管理员改全局配置时运行时推送，**约 2 秒生效** |

## 二、管理员功能

管理员在普通用户全部能力之上，额外获得以下三处入口：**管理后台**、**模板库**、**权限**，以及全局配置的编辑权。

### 1. 管理后台 · 容器管理

- **平台总览卡**：用户数 / 容器记录数 / Docker 运行中容器数 / 单容器资源限额（CPU、内存、PIDs）
- **全用户容器列表**：用户名 + 工号、Docker 状态、台账状态、健康探测、重启次数、启动时间、最近活动；台账有记录但容器已不存在时显式标注
- **搜索与筛选**：按用户名 / 工号 / 状态过滤；5 秒自动刷新
- **实时资源采样**（可开关）：并行 `docker stats` 采集各容器 CPU 占用率、内存用量/限额
- **批量操作**：勾选多行后批量重启 / 停止 / 销毁
- **单行操作**：
  - **日志**：双 Tab 模态窗口——容器日志（tail 100–2000 行可选，mono 渲染自动滚底）+ **请求日志**（该用户经平台的 API 调用记录）
  - **重启**：保留数据卷，健康探测通过后自动重建 SSE Pump
  - **更新镜像**（recreate）：用最新 Agent 镜像重建容器，**保留工作区与数据卷**
  - **停止**
  - **销毁**：删容器 + 删卷（台账保留，状态置 `destroyed`），需**输入容器名二次确认**
- **生命周期审计**：`/api/admin/audit` 记录容器的创建/启动/停止/销毁等操作轨迹
- 所有操作串行锁定 + toast 反馈，避免并发误操作

### 2. 管理后台 · 用户体验看板

- **粒度切换**：日 / 周 / 月 / 年，粒度驱动默认统计窗口
- **过滤维度**：按工号、按模型厂商
- **分层指标**：
  | 层 | 关注点 |
  |---|---|
  | L0 用户 | 活跃用户数、新增、留存 |
  | L1 结果 | 会话数、消息数、完成率 |
  | L2 效率 | 回合数、耗时、TTFT |
  | L3 过程 | 工具调用分布、LLM 上游状态码 |
  | L4 满意度 | 点赞/点踩比、原因码分布 |
- **趋势图**：核心指标随时间变化（recharts）
- **工具排行与调用明细**：哪些工具被调用最多、失败率如何，可下钻到单次调用
- **LLM 上游观测**：按厂商/模型统计 TTFT、状态码分布
- **回合明细**：逐回合下钻查看
- **反馈明细**：点踩原因码、补充文本、上下文快照
- **历史回补**（backfill）：为既有数据补算指标

### 3. PPTX 共享模板库管理

- 物理副本单点存储于 `agent-pptx-lib` 卷，**所有用户容器只读挂载**（用户侧模板选择器的数据源）
- **统计卡**：模板总数、已上架数、样式数、库占用
- **导入入库**：上传 `.pptx`（≤25MB），走规范化流水线并返回**规范化报告**（修正了哪些问题）
- **种子重跑**：一键重灌内置种子模板，按内容去重不重复入库
- **缩略图**：支持手动上传；未提供时由浏览器端渲染自动补齐
- **元数据管理**：编辑名称/描述/标签、**上架 / 下架**（下架后用户选择器不可见）、删除
- **详情弹窗**：查看模板元信息、样式与预览
- 用户侧样例库受 `pptx_library_allow_samples` 开关门控

### 4. 知识库权限管理

- **凭据管理**（`/api/admin/kb-keys`）：录入 fastk 知识库的访问凭据、轮换、删除（删除**连带撤销**相关授权）；接口永不返回密钥明文
- **用户授权**（`/api/admin/kb-grants`）：为指定用户授予/撤销某知识库访问权（软删除，保留历史）
- **双列表视图**：待授权用户列表 + 已授权列表，点击即授权/撤销
- **矩阵视图**：用户 × 知识库 的点击式授权矩阵（`/api/admin/kb-user-access`）
- 授权即时生效于容器侧白名单代理，撤销后历史引用徽章同步 403

### 5. 全局配置管理（仅 admin）

| 对象 | 管理员能力 |
|---|---|
| **LLM Provider** | 平台级 Provider / 模型 CRUD（OpenAI-compatible、自定义 baseURL），API key 脱敏展示 |
| **MCP Server** | 全局 MCP 增删改查 + 启停；**内置 MCP 总闸**（全局停用后用户个人开关一律置灰） |
| **Skills** | 全局 Skill 增删改查（直接编辑 `SKILL.md`：YAML frontmatter + Markdown）；**内置 Skill 可见性**控制 |
| **生效方式** | 保存后注入时消毒（MCP 过滤 / 内置 MCP·插件注入 / LLM Proxy 改写 / 模型覆盖 / Provider 白名单）；运行时推送约 2 秒生效，或用户自助「重载配置」 |

## 三、角色权限对照表

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 注册 / 登录 / 启动自己的容器 | ✅ | ✅ |
| 对话、会话、项目空间、附件、文件面板 | ✅ | ✅ |
| 快捷技能（PPT / 流程图）、模板与风格选择 | ✅ | ✅ |
| 知识库检索与引用徽章（**限已授权库**） | ✅ | ✅ |
| 点赞 / 点踩反馈 | ✅ | ✅ |
| 用户级配置（个人 Provider / MCP / 内置 MCP 开关） | ✅ | ✅ |
| 项目级配置（`opencode.json` + Skill zip 导入） | ✅ | ✅ |
| 重载自己的容器配置 | ✅ | ✅ |
| 查看全局配置（Provider / Skill；MCP 列表不可见） | 只读 | ✅ |
| 全局配置写入（Provider / MCP / Skill / 内置项开关） | ❌ | ✅ |
| 管理后台：容器总览 / 列表 / 日志 / 请求日志 / 资源采样 | ❌ | ✅ |
| 容器操作：重启 / 停止 / 更新镜像 / 销毁 / 批量操作 | ❌ | ✅ |
| 生命周期审计 | ❌ | ✅ |
| 用户体验看板（L0–L4 指标、趋势、下钻、回补） | ❌ | ✅ |
| PPTX 模板库管理（导入 / 上下架 / 缩略图 / 删除） | ❌（仅使用） | ✅ |
| 知识库凭据与授权管理 | ❌ | ✅ |

> 说明：全局配置的 **MCP 写入/启停/删除**与**内置项管理**在后端为 `require_admin` 强守卫；全局 **Provider / Skill 写入**接口目前只要求登录态（`get_current_user`），前端不为普通用户渲染入口——按最小权限原则，后续应收紧为 admin。
